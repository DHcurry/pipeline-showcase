# 考公知识库

用户个人的公务员考试备考知识库，核心是"错题驱动 + 艾宾浩斯复习 + 考官手法反推"闭环。

- Obsidian vault：`vault/`（218 个 md 文件）

| 模块 | 内容 | 数量 |

| `vault/知识点/` | 各题型解题体系（主旨题/逻辑填空/语句填空/语句排序/细节判断/下文推断/资料分析等） | 11 |

## 核心方法论

1. **错题录入**：做题 → 录入错题（错误类型：概念混淆/审题不仔细/计算失误/公式记错/粗心/时间分配不当）
2. **体系化**：每道错题挂 ``知识点/xxx解题体系``，按标签注册表严格归类
3. **考官手法**：选定答案后反推"考官怎么从正确答案派生出干扰项"
4. **间隔复习**：艾宾浩斯 1→2→4→7→15→30 天；闪卡推送按掌握等级（新学→精通）动态调整
