# 自媒体口播工作台

## 项目概述
一个帮助内容创作者进行口播文案创作的工具平台。核心功能围绕"模仿"和"写作"两大方向。

## 核心功能

### 1. 内容获取与分析
- **平台支持**：知乎、B站、抖音、小红书等主流内容平台
- **获取方式**：
  - 搜索高赞/热门内容
  - 根据链接直接抽取文案
- **内容处理**：提取文案、分析结构、识别风格特征

### 2. 模仿创作
- **风格分析**：分析原文的写作风格、节奏、用词特点
- **结构模仿**：保持原文的逻辑结构和表达框架
- **内容再创**：基于原文风格创作新内容，保持风格一致性

## 技术架构考虑

### 数据获取层
- **知乎**：zhihu-mcp 或 zhihu-scraper
- **B站**：bili2text 或 BiliBili_VideoRead_MCP
- **抖音**：transcriptgenerate 或 CopyPilot
- **小红书**：redbooks 或 xhs_searchMcp

### AI处理层
- 文案风格分析
- 结构化提取
- 模仿生成

### 用户界面
- 内容浏览与搜索
- 文案预览与编辑
- 创作工作台

## 风险与注意事项
- 平台反爬机制
- 内容版权问题
- API 稳定性
