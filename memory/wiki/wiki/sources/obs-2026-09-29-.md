# ⭐ Observation: 三层日志系统（后端落盘+客户端上报+全局异常钩子）落地

三层日志系统落地（2026-09-30凌晨，用户明确要求"每次都记录日志方便排查"）：①后端 services/logger.ts——logLine(tag,level,msg,data) 落盘 runtime/logs/YYYY-MM-DD.log（UTC日期），访问日志（排除/health噪音）+app.onError+listener errorHandler 全接入，写日志失败绝不影响服务；②POST /api/client_logs 接收浏览器上报→同文件落盘（[client]标签）；③前端 lib/client-log.ts——clientLog三路留痕（console+localStorage环形80条+上报后端keepalive），installGlobalErrorLogging 挂 window.onerror/unhandledrejection（抓原生JSON.parse "Unexpected token '<'"类未捕获异常），CreateTab mount时装载；readJson非JSON分支自动clientLog。另修：style_profiles建显式静态GET route（绕开rewrite在后端重启/HMR窗口吐HTML错误页的风险，带JSON包装+x-wf-router头）。排查方法：看 runtime/logs/当天.log，[client]行=浏览器现场，[http]行=请求时序，[ERROR]=堆栈。当时无法复现"点击创作报错"——判定为我编辑代码期间tsx watch/HMR重启窗口的rewrite上游拒连瞬态。
