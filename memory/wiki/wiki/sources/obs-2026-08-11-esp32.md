# ⭐ Observation: ESP32 桌面机器人项目架构讨论

用户计划用 ESP32 做桌面机器人，外接设备包括屏幕、摄像头、麦克风等，全部挂在 ESP32 上（而非 PC）。已确认架构：Pi 通过串口/WiFi 与 ESP32 固件通信，固件是唯一中介（驱动层）。关键结论：(1) 设备发现靠 I2C 总线扫描 + 接线图，GPIO 设备无法软件探测；(2) 调试靠固件内置命令层 #ls/#scan/#status/#diag/#log + 串口日志，物理验证需用户配合；(3) 摄像头 JPEG 帧可传给我直接看图，麦克风建议只做唤醒词、识别放 PC，屏幕只能发绘制指令无法回看；(4) 串口带宽是瓶颈，建议用 ESP32 WiFi。下一步：设计统一命令协议 + 固件模板，等板子到手先做 #ls 调试框架验证。用户机器已有 Python 3.11.9，无 pyserial/esptool（需 pip 安装）。当前 ESP32 未插，COM3/COM4 是蓝牙串口。
