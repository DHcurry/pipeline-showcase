# 标签注册表.md

## Summary

This document is a 标签注册表 (tag registry) for a wrong-question review system (错题系统) used in Chinese civil service exam (行测) preparation, covering 言语理解 (verbal comprehension) and 资料分析 (data analysis). It enforces a strict controlled-vocabulary rule: wrong-question tags must be selected only from this registry and users must not invent their own words; any new tag must first be registered here before being propagated to the corresponding knowledge-point or pitfall files.

The registry organizes tags into three layers. The 题型层 (question type layer) lists one mandatory tag per question: 逻辑填空, 主旨题, 细节判断, 语句填空, 下文推断, 语句排序, and 资料分析, each mapped to a solution-system knowledge file. The 知识点层 (knowledge point layer) maps fine-grained tags to section headings inside those files (e.g., 转折关系, 总分结构, 三不原则, 话题捆绑 for verbal comprehension; 基础概念, 增长类公式, 材料分类 categories for data analysis). The 坑点层 (pitfall layer) maps tags to examiner-trick files, including systematically coded pitfalls such as D01–D13 for 细节判断 and S01–S04 for 语句排序.

For 资料分析, the registry includes a single question-type tag, knowledge tags for formulas, calculation shortcuts and material categories (宏观经济, 贸易类, 民生保障, 农业农村, 交通运输, 房地产金融), and five pitfall tags (时间陷阱, 单位陷阱, 概念陷阱, 材料定位陷阱, 速算陷阱). The document also declares a 维护规则 (maintenance rules) section, though its body appears empty in this extract.

## Key Takeaways

- 错题 tags must be strictly selected from this registry; self-invented tags are not allowed.
- New tags must be registered in the registry first, then updated in the corresponding knowledge-point/pitfall files.
- Tags are organized into three layers: 题型层 (question type), 知识点层 (knowledge point), and 坑点层 (pitfall).
- Verbal comprehension covers six question types: 逻辑填空, 主旨题, 细节判断, 语句填空, 下文推断, 语句排序, each mapped to a solution-system file.
- Pitfall tags use systematic codes, e.g., D01–D13 for 细节判断 and S01–S04 for 语句排序.
- 资料分析 has its own tags for formulas, material categories, and five named traps (time, unit, concept, material location, calculation).
- The 维护规则 (maintenance rules) section is declared but appears empty in the extract.
