# 逻辑填空解题体系.md

## Summary

该文档是一份针对行测"言语理解"模块"逻辑填空"题型的完整解题体系（v3版本，2026-07-11重构），以纯做题思路为核心：三层分析法 + 八大题型分类 + 错题精华提炼。作者将词义辨析内容全部迁移至独立的"词语辨析库"，本文档专注于解题方法论本身。

文档核心框架为"三层分析法"：第一层语境分析（定方向，包括感情色彩褒/贬/中性与语境范围宏观/微观）；第二层逻辑关系（找线索，覆盖转折、并列递进、反义并列、解释对应、因果目的、引号比喻、政策搭配等七大逻辑关系）；第三层词语辨析（锁答案，指向词语辨析库）。八大题型分类索引按转折关系型、并列递进型、反义并列型、解释对应型、因果目的型、成语辨析型、政策搭配型、引号比喻型分类，并统计了各类型的错题数量与判断信号。

文档还提炼了多项技法：反义并列"不再A而是B"需严格反义且先锁空；引号不改变词义核心侧重点、仅放宽搭配限制；因果目的型需前后文手段达成目的；"倒逼/促进/迫使"三词方向与色彩辨析；多空题破题优先级（先做反义并列、程度限定、搭配排除最明确的空）；以及"显性对应vs隐性对应"区分表与核心新技法"隐性反推法"——当转折+后文价值判断同时出现时，从后文价值结论反向推导前文否定的维度。文末给出六步做题流程并关联了其他题型解题体系及考官手法笔记。

## Key Takeaways

- 逻辑填空题以三层分析法为主线：语境分析定方向→逻辑关系找线索→词语辨析锁答案。
- 八大题型分类：转折、并列递进、反义并列、解释对应、因果目的、成语辨析、政策搭配、引号比喻，一道题可能触发多个分类，按最核心定类。
- 反义并列型核心公式：'不再A，而是B'要求A与B严格反义，考场操作是先锁反义更明确的那一空。
- 引号不改变词语核心侧重点，仅放宽搭配限制（如'一步到位'加引号仍只能延伸为效率高、一次办成）。
- 隐性反推法（核心新技法）：转折+后文价值判断时，从后文价值结论反向推导前文被否定的维度，而非直接看前文。
- '倒逼'为下游→上游反向中性词，'促进'为顺向正向，'迫使'为外界强制偏贬义。
- 多空题破题顺序：先做反义/并列提示最明确的空→程度限定最明确的空→搭配排除最明显的空→逐空交叉验证。
- 两个独立技巧推导出同一答案时答案可靠性极高（如目的对应+搭配排除双重验证）。
