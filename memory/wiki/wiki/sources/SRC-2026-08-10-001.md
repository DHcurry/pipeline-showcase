# README.md

## Summary

This README documents 考公错题本 (Civil Service Exam Error Notebook), a personal study system for tracking mistakes made while preparing for the Chinese civil service exam (行测/申论). The architecture layers a Memory MCP knowledge-graph layer on top of an Obsidian vault: the MCP layer handles entities, relations, and queries while the Obsidian vault holds detailed notes and graph views, with Python scripts providing fast entry, weekly review, and visualization.

The system offers three ways to record mistakes: telling an AI agent in natural language (recommended), using the command-line script add_error.py (interactive or non-interactive), or manually copying a template into the vault/错题 folder. The vault is organized into folders for wrong questions (错题), knowledge points (知识点), error types (错误类型), auto-generated weekly reviews (复习), and templates (模板), with a homepage dashboard powered by the Dataview plugin.

Core workflows include Ebbinghaus spaced-repetition review (intervals of 1→2→4→7→15→30 days) via ebbinghaus.py, weekly review report generation via weekly_review.py, and knowledge graph visualization via visualize_graph.py. The README also catalogs six error types (concept confusion, careless reading, calculation errors, wrong formulas, carelessness, and poor time allocation) with improvement strategies, plus recommended Obsidian community plugins and a summary of optional Memory MCP tools available after restarting Hermes for cross-session queries.

## Key Takeaways

- Architecture combines Memory MCP (knowledge graph layer) with an Obsidian vault (note layer), connected by Python scripts.
- Three input methods for logging errors: natural-language agent input (recommended), CLI scripts, or manual template copying.
- Ebbinghaus spaced repetition uses intervals of 1, 2, 4, 7, 15, and 30 days, driven by the ebbinghaus.py script.
- The vault structure separates wrong questions, knowledge points, error types, weekly reviews, and templates for systematic review.
- Dataview is a required Obsidian plugin; Calendar, Minimal Theme, and Kanban are optional.
- Six error types are defined, each with a description and improvement direction (e.g., concept confusion → comparative memorization with concrete examples).
- Knowledge graph nodes with the most connections indicate the weakest knowledge areas.
- Memory MCP tools (create_entities, create_relations, search_nodes, open_nodes) are optional and mainly for cross-session queries after restarting Hermes.
