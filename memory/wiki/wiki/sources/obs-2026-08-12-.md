# ⭐ Observation: 记录算法三段式与技能"非自动"真相

核实 pi-hermes-memory v0.9.3 源码后确认两点：1) 记录判断算法是"信号触发→LLM规则化审判→JSON契约+硬闸门"三段式，排除规则核心句为"只存持久事实，不存任务进度/会话结果/临时状态"，老化规则为超30天未引用条目可删；2) README 声称的"Skill Auto-Extraction（复杂任务后自动询问存技能）"在代码中不存在——后台复习prompt明确禁止碰技能，技能创建/更新完全靠主代理主动调用 skill_manage（真实实现了 create/view/patch/update/edit/delete，patch 为段落级替换+版本号+1）。已在《记忆的工程学》书中新增第七章附（判断算法）并修正第十二章描述。
