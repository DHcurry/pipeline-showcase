## 速查口诀

```
现基隔年分清楚，增率增量别糊涂。
比重平均和倍数，升降判断比ab。
增长比较大大大，一大一小看乘积。
特殊分数要记牢，截位直除看差距。
```

## 一、基础概念（16个）

### 1.1 时间类

| 概念 | 定义 | 示例 |
|------|------|------|
| **现期** | 材料给出的统计时间 | 材料写"2026年GDP" → 2026年是现期 |
| **基期** | 题目要求的早于现期的时间 | 问"2025年GDP" → 2025年是基期 |
| **间隔基期** | 与现期间隔1个统计周期 | 现期2026，问2024 → 2024是间隔基期 |
| **年均增长基期** | 普通时间段基期=起始年；五年规划基期=规划前一年 | 2021-2025年→基期2021；十四五(2021-2025)→基期2020 |

### 1.2 指标类

| 概念 | 定义 | 识别 |
|------|------|------|
| **流量指标** | 一段时期的累计发生额 | "全年GDP""1-6月社零" |
| **存量指标** | 某个时点的瞬时数值 | "年末存款余额""月末库存" |
| **同比** | 与上年同期比 | 2026年3月 vs 2025年3月 |
| **环比** | 与上一个相邻周期比 | 2026年3月 vs 2026年2月；2026年Q1 vs 2025年Q4 |
| **顺差** | 出口>进口 | 顺差额=出口-进口 |
| **逆差** | 出口<进口 | 逆差额=进口-出口 |
| **百分点** | 两个百分数的差值 | 增速从10%到12% → 上升2个百分点 |
| **成数/翻番** | 1成=10%；翻n番=原数×2ⁿ | 翻一番=×2，翻两番=×4 |

### 1.3 统计材料类

```
表格材料：横轴=时间/分类，纵轴=统计指标
图表材料：折线=率，柱状=量，饼图=比重
注释：所有*标注内容必须先读，必有考点
单位换算：1亿=10⁴万，1吨=1000公斤，1公顷=15亩
人口增长率单位为‰（千分号）
```

## 二、增长类公式（18个）

### 2.1 普通增长（时间差1年）

```
基期量 = 现期量 - 增长量
基期量 = 现期量 / (1 + 增长率)        ← 最常见
增长量 = 现期量 - 基期量
增长量 = 基期量 × 增长率
增长量 = [现期量 / (1+增长率)] × 增长率  ← 参考答案公式
增长率 = (现期量 - 基期量) / 基期量
增长率 = 现期量 / 基期量 - 1
现期量 = 基期量 + 增长量
现期量 = 基期量 × (1 + 增长率)
```

### 2.2 特殊增长

| 类型 | 公式 | 难点 |
|------|------|------|
| **间隔增长率** | r = r₁ + r₂ + r₁×r₂ | 当r₁、r₂均＜10%时，r₁×r₂可忽略 |
| **间隔基期量** | 现期量 / (1+间隔增长率) | 先求间隔增长率，再求基期 |
| **混合增长率** | 整体增速介于各部分之间，偏向基期量大的部分 | 十字交叉法，线段法 |
| **年均增长量** | (现期量 - 基期量) / n | n=年份差，注意基期取法 |
| **年均增长率** | 现期量 = 基期量 × (1+r)ⁿ | 开方计算，代入排除 |
| **乘积增长率** | r = r₁ + r₂ + r₁×r₂ | 总量=单价×数量时的总增速 |
| **比值增长率** | r = (a-b) / (1+b) | 平均数/比值的同比增速 |

### 2.3 增长比较

**增长量比较（高频）：**
```
大大则大：现期量大、增长率大 → 增长量一定大
一大一小：看「现期量 × 增长率」的乘积，乘积大的增长量大
```

**增长率比较：**
```
现期/基期 ≥ 2 → 直接比较「现期量/基期量」
现期/基期 < 2 → 比较「增长量/基期量」
```

## 三、比例类公式（12个）

### 3.1 基础比例（比重/平均数/倍数通用）

```
现期比例 = 分子A / 分母B
基期比例 = (A/B) × (1+b)/(1+a)
  a = A的增长率，b = B的增长率
```

### 3.2 两期比例变化

```
比例升降判断：
  a > b → 比例上升
  a < b → 比例下降
  a = b → 比例不变

比重变化量 = (A/B) × (a-b)/(1+a)   ← 结果一定小于|a-b|
平均数增长率 = (a-b)/(1+b)

倍数特殊表述：
  A是B的n倍 → A/B = n
  A比B多n倍 → A/B = n+1    ← 易错！
```

### 3.3 比例衍生

```
部分量 = 整体量 × 比重
整体量 = 部分量 / 比重
总量 = 平均数 × 份数

利润率 = 利润总额 / 营业收入    ← 资料分析口径，非成本利润率
产销率 = 销量 / 产量
```

## 四、速算技巧（6个）

| 技巧 | 条件 | 操作 |
|------|------|------|
| **估算法** | 选项差距≥10% | 所有数值保留前2位有效数字 |
| **直除法** | 选项差距<10% | 分子不动，分母保留前3位，除到能区分 |
| **特殊分数法** | 增长率≈1/n | 增长量=现期/(n+1)；减少量=现期/(n-1) |
| **分数比较** | 比较大小 | 分子大分母小→大；同大同小→比分子增速 |
| **尾数法** | 精确加减，尾数不同 | 只算最后几位 |
| **截位修正** | 选项差距<5% | 分母截位后反向修正误差 |
