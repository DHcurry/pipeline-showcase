## 做题流程

```
1. 什么题型？ → 打开对应手册
2. 按手册的"做题检查流程"逐个排除
3. 选定答案后，反推：考官是怎么从正确答案造出其他选项的？
   - 能解释所有干扰项 = 选对了
4. 做错了 → 录入错题 + 更新坑点手册
```

> **考官派生法**是贯穿所有题型的思维方式。
> 核心：做完题反着想——正确答案怎么变出其他三个？
