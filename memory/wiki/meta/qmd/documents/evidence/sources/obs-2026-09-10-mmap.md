# 🔍 Observation: MMAP 思维导图开源查看方案部署完成

为 Windows 10 用户部署了 MindManager .mmap 文件的开源查看方案：1) mmap-file-viewer (GitHub yeshan-jun/mmap-file-viewer) 浏览器可视化查看器，位于 C:\Users\16575\mmap-viewer\，启动脚本 C:\Users\16575\打开MMAP查看器.bat（python -m http.server 8080 + 自动开浏览器），已验证 HTTP 200；2) mmap-tools Python 库 + mmap_open.py 便捷脚本（info/tree/export/export_all/find），已实测将 算法总结.mmap 导出为 Markdown。关键坑：GitHub 直连被重置需用 ghproxy.net 镜像；Windows GBK 控制台需 PYTHONIOENCODING=utf-8。用户大量 .mmap 文件位于 OneDrive（公务员/算法笔记）。
