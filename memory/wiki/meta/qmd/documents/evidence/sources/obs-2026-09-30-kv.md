# 🔍 Observation: KV缓存命中率诊断：冷启动+新内容当轮不命中所致

诊断 context-manager 扩展的"KV 缓存命中率低"：kv-cache.json 实测历史总命中 99.3%（机制完全健康，每轮 cacheRead 增量≈上一轮 input 精确衔接）。当前会话 90.6% 偏低的原因按贡献排序：①新会话冷启动（闲置9.75h后首条 31,825 token 仅命中64）；②上下文小（86K）时每轮新增 tool 结果(~7K)占比天然高，命中率随上下文增长而升高（昨天500K上下文时99.8%）；③大工具返回当轮全价（63%单轮值）；④5条 usage=0 记录是 errorMessage 报错响应。Pi footer 的 CH% 只取最新一条 assistant 消息，瞬时波动 63%~99%。cacheWrite 恒为0是 xiaomi mimo 网关只报 cached_tokens 的正常行为。
