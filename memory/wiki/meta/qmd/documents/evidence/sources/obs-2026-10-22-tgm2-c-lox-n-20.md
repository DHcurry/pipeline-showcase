# ⭐ Observation: TGM2"C组低"不可证：LOX替代叙事+功效测算(n≈20/组仍翻不了方向)

用户坚持要"证明C组TGM2低"，已明确告知不可行并给出替代方案。新增：①TGM2蛋白组构成核查（Q9WVJ6独立成组、无共享蛋白）；②Fig6 LOX箱线图：LOX是数据中真正C组低的蛋白（log2FC=-1.05, Welch p=2.1e-4 ***），与TGM2直接互作(score 0.556)，可换叙事为"TGM2-LOX轴"；③功效测算：Tgm2组内SD=0.248 log2, d=0.90, 当前效能0.42, 需n≈20/组才显著但方向只能是"C高"，加样本永远翻不了方向；④三条正路：LOX叙事/WB-qPCR验证/TGM2活性层面(交联产物、酶活)。修正了一个索引bug：DE表RangeIndex与全矩阵原始行号错位导致LOX取错行，已改用row_idx对齐。产物E:\TGM2_analysis\新增Fig6与power_and_lox_stats.txt。
