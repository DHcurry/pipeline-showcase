# ⭐ Observation: 考公知识库 Dataview 统计仪表板完成

考公知识库创建了 Dataview 驱动的统计仪表板：
1. 首页.md - 数据总览、掌握度分布、复习计划、错题分析、成长曲线
2. 统计.md - 深度分析：核心指标、题型分布、错误类型、掌握度分析、复习分析、标签分析、学习趋势、学习建议

关键 Dataview 功能：
- dv.pages() 查询各目录文件
- filter() 按条件筛选
- FLATTEN 展开标签
- dv.table() 表格展示
- dv.paragraph() 文本展示
- dataviewjs 自定义计算

页面使用 cssclass: dashboard 启用仪表板样式。
