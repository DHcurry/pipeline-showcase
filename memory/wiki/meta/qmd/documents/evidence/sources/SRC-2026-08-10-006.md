# README.md

## Summary

This README serves as the home page (首页) for a Chinese vocabulary discrimination study library ("逻辑填空·词语辨析库") built as an Obsidian vault. Its core premise is that logical fill-in-the-blank questions (逻辑填空) in Chinese exams hinge on word discrimination (词语辨析) — accumulating the differences between word groups allows one to lock onto the correct option at a glance.

The vault is organized around structured metadata per word group: error type (类别), review stage (复习阶段), and next review date (下次复习). Dataview queries power three views: a full overview table of all entries, a category browser grouped by error type, and a "today's review" list filtering entries whose next review date has arrived and whose review stage is below 6.

Workflow automation is provided through two Python scripts: add_vocab.py for entering new word groups and ebbinghaus.py for generating the day's review plan, indicating a spaced-repetition system based on the Ebbinghaus forgetting curve.

## Key Takeaways

- 逻辑填空 (logical fill-in-the-blank) questions are fundamentally about 词语辨析 (word discrimination).
- The vault stores per-entry metadata: error_type, review_stage, and next_review to drive review scheduling.
- A spaced-repetition loop runs until review_stage reaches 6, after which entries presumably stop being scheduled.
- Two Python scripts automate the workflow: add_vocab.py for new entries and ebbinghaus.py for daily review plans.
- Dataview queries provide overview, category browsing, and today's due-review views directly in Obsidian.
