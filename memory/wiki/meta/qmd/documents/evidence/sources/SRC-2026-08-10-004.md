# 错题图谱.md

## Summary

This source is an Obsidian note titled "错题图谱·按错误类型索引" (Mistake Atlas: Index by Error Type), tagged for 行测 (civil service aptitude test) 言语理解 (verbal comprehension) study. It functions as an auto-generated index that groups wrong-answer questions (错题) by question type and error type.

The note relies on Dataview queries to dynamically group all wrong questions by sub_category (question type), displaying each question's link, error_type, and mastery level. It also provides two advanced query examples: listing questions not yet mastered (mastery = 0) and questions added within the last 7 days. Categorization is driven by a convention where each wrong question's bottom links to a ``知识点/xxx解题体系`` note, enabling automatic classification.

The note closes with links to related indexes: the 标签注册表 (tag registry) and the 考官手法 (examiner's question-crafting techniques) index. It is essentially a dashboard/organizational layer over a wrong-question bank rather than standalone study content.

## Key Takeaways

- The note is a dynamic index that auto-groups wrong questions by question type (sub_category) and error type using Dataview queries.
- Each wrong question is classified by linking to a ``知识点/xxx解题体系`` note at its bottom, which drives automatic grouping.
- Mastery tracking (mastery field) is used to filter unmastered questions (mastery = 0) for targeted review.
- A recency query surfaces wrong questions added within the last 7 days for timely review.
- The atlas links out to a tag registry (标签注册表) and an examiner-techniques index (考官手法/README).
