# README.md

## Summary

This source is the README/home index page of a Chinese exam-preparation knowledge base focused on examiners' question-setting techniques (考官命题手法索引). It is organized as a navigation hub linking to per-question-type "pitfall manuals" (坑点手册) and knowledge-system pages for the 言语理解 (verbal comprehension) module — covering 逻辑填空, 主旨题, 细节判断, 语句填空, 下文推断, and 语句排序 — plus a 资料分析 (data analysis) module. Each question type has a dedicated pitfall manual and an index of verified wrong questions, with the wrong-question indexes migrated to Dataview automatic queries.

The page documents a four-step answering workflow: identify the question type and open the matching manual, work through the manual's checking process to eliminate traps, and after selecting an answer, reverse-engineer how the examiner derived the other options from the correct answer. The core philosophy is the "考官派生法" (examiner derivation method): if you can explain all distractors as derivations of the correct answer, your choice is right; when you get a question wrong, you log it and update the pitfall manual. The page closes with quick-navigation sections listing pitfall manuals, knowledge systems, and index pages (wrong-question map and tag registry).

## Key Takeaways

- The knowledge base is organized by question type, each with a dedicated pitfall manual (坑点手册) and a verified wrong-question index.
- The core method is 考官派生法: after choosing an answer, reverse-engineer how the examiner derived each distractor from the correct answer.
- Being able to explain every interference option is treated as proof that the selected answer is correct.
- Wrong answers trigger a feedback loop: log the error and update the corresponding pitfall manual.
- Wrong-question indexes have been migrated to Dataview automatic queries rather than manual lists.
- Covered modules: 言语理解 (six question types) and 资料分析.
