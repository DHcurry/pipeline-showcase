# ⭐ Observation: eta网格扩到100：TypeI减半至0.26但Power降至0.72

eta网格扩展实验（48单元×10重复，global_lasso_emm，网格扩到[0.5,3,7,13,20,25,35,50,75,100]）完成。三方对比v7修复前→修复后旧网格→修复后扩展网格：TypeI 0.495→0.516→0.260（减半），Nsel 11.0→11.4→6.13，Power 0.894→0.845→0.721（代价），RMSE 0.335→0.355→0.334。证实BIC在旧网格上界的堆积是TypeI膨胀主因。但新网格仍有162/480（34%）选在上界100，eta=100时TypeI仍0.179；N=3000的TypeI(0.287)仍高于N=1000(0.234)，eta未随N缩放的问题仍在。与v7的EM版(全局基础LASSO: Power 0.975/TypeI 0.181)相比，EMM扩展网格后(Power 0.721/TypeI 0.260)在两个维度上仍被EM支配。结果存于模拟结果/EMM_eta扩展_全局基础EMM_结果.xlsx。
